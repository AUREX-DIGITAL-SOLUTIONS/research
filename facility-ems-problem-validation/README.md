# Facility EMS Problem Validation

**Status:** Starter project
**Institution:** Aurex Digital Solutions
**Context:** Kenya-focused facility and distributed-energy research
**Owner:** Founder-led interim stewardship

This project investigates whether a defined, material, and addressable facility-level energy-management problem exists before Aurex scopes a Facility EMS prototype.

It is a research project, not a programme, pilot, deployment, or claim that a national DERMS need has been validated.
